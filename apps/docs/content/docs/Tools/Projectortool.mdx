## 二、像素画投影生成器

像素画投影生成器能够在浏览器本地将任意图片文件转化为 Minecraft 对应的 `.litematic` 格式投影。在游戏中使用 Litematica 投影导入该文件，即可直接在地面投影出像素画，极大地降低了红石音乐地图画以及像素艺术创作的难度。

### ⚙️ 高级算法设置
为了使生成的方块效果更加逼真、平滑，工具集成了以下高级处理选项：
* 🌀 **启用抖动算法 (Floyd-Steinberg)**：通过误差扩散在方块过渡时消除生硬的色彩分界（色带），使色彩过渡自然。
* ✨ **智能优化 (去噪与平滑)**：对图片进行轻微均值滤波，消除图像中的高频杂色点。
* 📈 **增强对比度**：自动进行通道色彩拉伸，使方块拼合出来的色彩更加饱满、突出。
* 🏁 **棋盘式混合**：通过规则的像素块错开排列方式来模拟更多的中间混合颜色。

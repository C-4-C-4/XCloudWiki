# 🛠️ iOS 视频自动播放修复与全站排版重构

在本次更新中，我们重点解决了一些长久以来的设备兼容性问题，并对全站的视觉结构进行了细致的微调。

## 🔧 更新内容与特性

### 1. 📱 iOS 与微信视频自动播放兼容
* **问题描述**：由于移动端系统（尤其是 iOS 及微信内置浏览器）对媒体自动播放的严格限制，首页视频背景会出现无法自动播放的情况。
* **解决方案**：引入了**智能手势解锁激活机制**，通过捕获用户的首次轻触交互，平滑恢复并自动播放背景视频，确保视觉体验不留白。

### 2. 📝 项目 README 架构重构
* 对项目根目录的 `README.md` 进行了整体框架的重写，使工程化目录、开发流程及贡献指南更具有可读性与条理性。

### 3. 🎨 视觉比例调优
* 对全站的间距、排版布局及字体比例进行了全面优化，确保在不同屏幕分辨率下都拥有舒适、均衡的视觉节奏。

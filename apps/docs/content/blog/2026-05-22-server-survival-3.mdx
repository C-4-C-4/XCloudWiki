# 🎮 生存 3 区正式开放与新功能上线

今天的服务器更新迎来重大硬件与玩法升级，生存 3 区正式向广大玩家敞开大门！

## 🚀 硬件升级与新服开放
* **升级 9950X 主机**：新增服务器 9950X 主机，**生存 3 区**正式开放，提供更流畅的联机与游戏体验。

---

## ⏳ 限时活动
* **圈地半价**：生存 3 区尊享圈地半价福利！活动时间：2026年5月22日 - 5月29日。
* **征讨蜂后**：前往征讨蜂后巢室获取征讨点数，可用于兑换限定背景框与头衔框。活动时间：2026年5月22日 - 6月10日。

---

## ✨ 新增功能与机制

### 1. 🐎 主城互动与动作指令
* **主城骑乘互动**：右键其他玩家即可骑乘到对方头上，增强社交趣味性。
* **丰富动作指令**：新增趴下 `/bellyflop`、旋转 `/spin`、坐下 `/gsit`、躺下 `/lay`、爬行 `/crawl` 指令。
* **随时随地坐下**：全服开放 `/sit` 指令，可原地进行坐下休息。

### 2. 🎴 系统升级
* **装备图鉴**：装备图鉴系统正式上线，方便收集与查阅。
* **解绑功能**：开放解绑服务，解绑物品时可自主选择消耗积分或金币。
* **主菜单优化**：对主菜单的传送界面进行了整体优化微调。

# 🐝 征讨世界蜂后巢室开启，多项系统平衡性微调

今天的更新将开启全新的副本挑战——蜂后巢室正式降临，并对服务器底层的多项机制进行了优化和平衡。

## 🔥 征讨世界副本开启
* **蜂后巢室上线**：本次开放普通、困难、炼狱三档难度。挑战难度越高，获得的专属材料与装备掉落越丰厚。
* **组队与竞速**：
  - 采用多人组队模式挑战时，可以享有更高的副本收益。
  - 新增了每周单人通关速度排行榜，向服务器最强发起挑战吧！
* **新增奇观**：引入了全新奇观「圣诞小镇」，游览该地即可解锁专属见闻录奖励。

---

## 🛠️ 平衡性微调与系统修复

* **技能与限制**：
  - **快速生长**：对 7 级 CD 进行了微调，现统一调整为 2 秒。
  - **地狱领地**：为了方便玩家在地狱大展拳脚，领地圈地高度上限正式增加至 300 格。
* **经济与交易**：
  - **交易实时化**：金币转账与商品出售的收益现在将 100% 实时到账，杜绝交易延迟。
* **Bug 修复**：
  - 修复了小镇红包无法正常领取的问题。
  - 修复了箱子商店附魔书购买异常的问题。
  - 修复了部分成就宝箱奖励发放失败的 Bug。

# 🚀 「新版附魔书查询系统」震撼上线！

亲爱的闲云玩家与维基共创者们：

我们非常高兴地宣布，**全新的附魔书查询系统**今天正式上线 Wiki！

在之前的版本中，虽然我们实现了对拓展附魔的毫秒级检索，但随着服务器附魔生态的不断丰富，很多玩家在组合装备附魔时遇到了“哪些附魔会互相冲突”、“不同等级的附魔具体属性是多少”等痛点。为了解决这些问题，我们对附魔书查询引擎进行了**全面的交互式重构**。

---

## 🌟 核心升级特性

### 1. 🔍 智能冲突诊断系统（Conflict Diagnostic System）
* **一键诊断冲突**：现在，只需在卡片列表中**点击任意一张附魔卡片**，系统将开启“冲突诊断模式”。
* **动态视觉警告**：数据库中所有与该附魔冲突的条目将被**自动标红警告**并显示“冲突”浮标。
* **联合诊断看板**：顶部会生成一张冲突诊断看板，展示具体的冲突数量和冲突条目，极大方便了玩家在出装前进行附魔兼容性评估。

### 2. 🧮 交互式等级在线调节
* **多级实时调整**：对于支持多等级的附魔（例如带有 $I \sim IV$ 级的附魔），卡片底部新增了灵活的等级调整按钮（`+` / `-`）。
* **数值/CD动态估算**：调整等级时，卡片上显示的**属性数值**和 **CD 冷却时间**会根据等级比例进行实时动态估算和渲染，让玩家无需翻阅多级文档即可掌握每级属性变化。

### 3. 👥 顶部联合编辑面板
* **致谢创作者**：为了致谢所有为本页面做出贡献的成员，顶部面板新增了“联合编辑人员”专区。
* **精致头像展示**：展示了页面开发与数据维护的核心编辑（如 `CCCC4444`、`satori1024`、`星`）的专属头像与具体职责分工。

# 🌾 渔夫职业点奖励与农业跨季机制大改

今天，服务器对深受大家喜爱的渔夫与农业两大核心玩法进行了体验调整与机制重构。

## 🎣 渔夫系统与经济调优
* **等级上限奖**：渔夫职业现已增设全新的职业点上限奖励，分别在渔夫等级达到 5级、10级、15级 时自动解锁。
* **快捷售卖**：新增「全部售卖」功能按钮。现已支持展示当日的剩余可卖出额度，极大优化了钓鱼狂热者的交互体验。

---

## 🚜 农业系统重大调整
为了降低玩家的维护成本，农业系统进行大改：
* **缺水不致死**：干旱（缺水）状态下的农作物将**仅仅停止生长，不再会自动枯死**。
* **跨季高存活**：优化了季节对作物的影响逻辑。除了凛冽的冬季外，作物跨越其他所有季节均可正常存活，不再会因为季节更替而大面积死亡。

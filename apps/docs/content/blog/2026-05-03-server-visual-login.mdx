# 🔑 可视化 UI 登录注册系统上线，崩服 Bug 彻底修复

今天的更新为玩家进服安全与便利性带来了大幅提升，并针对困扰服务器已久的致命崩溃 Bug 进行了彻底修复。

## ✨ 登录交互与服务器扩容
* **可视化 UI 登录**：告别在聊天框手动敲击 `/register` 或 `/login` 指令的传统繁琐操作，现已全面上线弹窗式可视化登录/注册 UI 界面，直接输入密码即可登录。
* **单区限额提升**：为了应对高峰期排队情况，我们将单区在线人数上限临时提升至 **60 人**。

---

## 🛠️ 重大系统崩溃修复
* **怒之领域恶性崩服 Bug 修复**：我们与核心开发团队彻夜排查，彻底定位并修复了由附魔属性“怒之领域”触发内存及计算栈溢出导致服务器恶性崩溃（崩服）的严重 Bug，恢复服务器的长期平稳运行。
* **领地箱子商店**：现在支持在玩家私人领地内部安全创建箱子商店，并且大幅优化了 `rtp`（随机传送）的边缘定位范围至 10000 格，减少传送到海里或虚空的问题。
* **常规修复**：修复了“致富乐”活动统计异常、邮件发送失败、玩家防具收纳袋提取异常等多项核心基础功能。

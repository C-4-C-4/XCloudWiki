# 📖 全新「图书馆」功能页面正式发布

今天，闲云 Wiki 迎来了玩家文化建设的重大更新——全新的**「图书馆」**功能页面正式上线！

这里不仅是一个知识库，更是属于闲云玩家自己的文化档案馆。

## 🌟 核心特色功能

### 1. 🔍 强劲的书籍检索引擎
* 针对图书馆特有的海量藏书，开发了轻量级但检索极精准的**分类与全文书名引擎**。玩家可以快速通过分类标签（历史、游玩故事、同人小说、建筑设计等）瞬间锁定想要阅读的文献。

### 2. 📚 沉浸式高保真毛玻璃 UI 阅读器
* **极致视觉美感**：阅读器界面采用了现代的**高保真毛玻璃（Glassmorphism）**拟物设计，营造静谧、沉浸的模拟翻书与阅读感受。
* **跨端流畅阅读**：精心调试了字距、行高及排版，在 PC 端与手机移动端均可实现完美的视觉呈现。

### 3. 🎨 开放收录与共创展示
本系统支持展示并持续收录：
* ✍️ 玩家的**原创图文投稿**与随笔。
* 🗺️ 闲云服务器内的**游玩故事、发展历史及个人传记**。
* 🎭 精美的**服务器同人周边作品**及攻略杂谈。

欢迎各位文学创作者与史官前往图书馆投稿，留下你在闲云的专属记忆！

# 🎣 渔夫经济公式微调与地标系统管理权限开放

今天的维护中，我们调整了渔夫的售卖收益上限公式，以优化服务器经济系统的平稳度；同时向玩家下放了更多地标管理自主权，并紧急修复了一个涉及经验收益的关键 Bug。

## ⚙️ 系统调整与权限开放
* **渔夫每日售鱼限额公式**：修改了渔夫每日可售卖海鲜以获取金币的额度计算方式，更新后的公式为：
  `当日基础额度 3500 + 渔夫等级 * 18`。
* **地标自主管理**：现在玩家对自己创建的地标将享有更完整的自主管理权。正式向创建者开放：地标重命名、地标删除以及允许玩家对公开地标进行评分的全新交互权限。

---

## 🛠️ 重大 Bug 修复
* **经验瓶失效 Bug 修复**：我们紧急定位并彻底修复了“大面额经验瓶在点击使用后无法给予玩家任何经验值”的恶性系统缺陷，现在大面额经验瓶已能 100% 正常提供对应的经验。

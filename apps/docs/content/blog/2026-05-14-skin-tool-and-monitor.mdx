# 🚀 一键换肤与服务监控上线，搜索性能深度调优

今天的更新带来两个重量级实用工具，并对全站底层的搜索机制及页面排版进行了深度优化。

## 🌟 新增功能与工具

### 1. 👕 「一键换肤工具」正式发布！
* **深度集成 MineSkin API**：现在玩家可以直接在 Wiki 页面上传自己的皮肤文件。
* **一键生成游戏指令**：上传后系统将自动调用 API 解析，并一键生成可直接在游戏内使用的换肤指令，省去繁琐的第三方操作。

### 2. 📊 实时「服务监控」页面上线
* **透明化数据展示**：通过接入 **UptimeRobot** 及 **Umami** API，实时公开展示闲云服务器运行状态、Wiki 网站的在线率以及全站访问流量数据。

---

## 🔍 系统调优与页面重构

### 1. ⚡ 全站搜索深度性能调优
* **模糊匹配逻辑 (Fuzzy Search)**：全面开启全文深层检索与模糊匹配。
* **联想与自动纠错**：支持输入关键词时的前缀自动联想，并具备了智能错别字自动纠错功能，大幅度提升检索的效率与容错率。

### 2. 🎨 页面布局与排版重构
* **重构视觉排版**：对全站多处页面布局进行了细致调优，重点重构了「维护日志」及「指令指南」的视觉结构，使信息展示的层级更为清晰。

### 3. 📖 攻略与指南深化
* **更改皮肤与指令功能**：深度优化了相关教程，补充完善了跨服传送指令以及详细的皮肤管理指令集。

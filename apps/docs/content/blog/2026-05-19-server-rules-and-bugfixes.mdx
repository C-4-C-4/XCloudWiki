# 📜 服务器群聊规范与拍卖行系统修复

本次更新旨在规范社区社交环境，并修复了游戏内拍卖行、成就和世界 BOSS 等多项系统 Bug。

## ⚖️ 服务器游戏规则修正
* **聊天规范**：为了便于出问题时回溯事件发生，小镇主要群聊大群**必须拉取官方机器人进群**。严禁在群内拉帮结派、阴阳怪气。违者将直接解散游戏内对应小镇，并将相关人员移出群聊。

---

## 🛠️ 系统修复与平衡性调整

* **拍卖行系统**：
  - 彻底修复了一键领取吞物品的 BUG（需要在服务器重启后生效）。
  - 修复了部分物品无法正常上架的 Bug。
  - **潜影盒算作单件**：上架拍卖行只计算为一个物品，现已支持直接出售成盒的鱼。
* **战斗与武器**：
  - **灵魂三叉戟**：修复了近战模式下无法正常触发伤害的问题。
  - **战斗力查看**：现在支持通过「潜行 + 右键」直接查看对方玩家的战斗力。
* **活动与怪物**：
  - **世界 BOSS**：修复了 BOSS 战后的奖励分配异常问题。
  - **征讨蜂后**：修复了召唤的小蜜蜂会无限续毒的问题。
* **农业与成就**：
  - **肥料系统**：修正了肥料的持续时间与文字描述对不上的问题。
  - **药罐子 22 成就**：修改了成就描述，由原先的“酿造”变更为“提交”。

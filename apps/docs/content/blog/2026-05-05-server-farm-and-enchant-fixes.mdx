# 🚜 温室与附魔拆卸界面系统修复

本次日常热更新重点修复了农夫种植与附魔管理模块的易用性 Bug，并提升了多处地图之间的传送与返回便捷度。

## 🛠️ 系统修复与调整

* **农业模块修复**：
  - 修复了温室玻璃判定失效导致作物无法得到温度加成的问题。
  - 修复了稻草人范围失效导致作物无法防止乌鸦啄食的问题。
* **附魔功能修复**：
  - 优化了附魔拆卸操作。修复了附魔拆卸界面最大只显示 8 个附魔的排版截断限制。

---

## 🗺️ 便捷性优化
* **渔场返回**：在渔场核心活动区域增设了专属的“返回”告示牌，方便玩家钓鱼满载后一键安全返回。
* **主城传送**：主城快捷传送界面中，新增了「闲云镇」地标的直达按钮。

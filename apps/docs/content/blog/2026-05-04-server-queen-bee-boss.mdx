# 🐝 野外 BOSS 蜂后降临，怪物刷新概率全面翻倍

今天，野外冒险世界迎来了强大的统领者——蜂后 BOSS 正式降临，猎手们准备好武器去挑战吧！

## ⚔️ 蜂后 BOSS 降临冒险世界
* **BOSS 刷新**：蜂后 BOSS 现已正式在冒险世界随机地点筑巢并刷新。
* **极品掉落**：击杀蜂后 BOSS 的玩家，将有概率获得特别定制的 **4 件专属蜂后盔甲** 与 **4 把专属蜂王武器**，自带特殊强化属性。

* **概率上调两倍**：为了让玩家更容易地挑战拓展生物并收集强化材料，我们全面上调了冒险世界里所有拓展特殊生物的刷新概率，上调至原先的**两倍**。
